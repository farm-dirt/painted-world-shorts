# Content playbook — categories, ideas, scripts

## What works on YouTube Shorts
Shorts are swiped in < 2 s, so the first frame + first sentence must create a question. Retention comes
from a clear story shape and a payoff near the end; loops (last line flows into the first) increase
rewatches. This cinematic painted look is strongest for **stories with a sense of place and wonder**:
myths and legends, true historical moments, "what if", journeys, small human dramas.

## Categories that suit this style (the niche is chosen per short, see SKILL.md Phase 2)
| Category | Why it suits the painted-world look |
|---|---|
| World mythology & folklore (any culture) | Gods, spirits and creatures in golden skies, forests, temples; transformations with light FX. |
| Weird-but-true history | Real places painted beautifully; characters act out the absurd moment. |
| Legends of the Philippines / SE Asia | Village, night, forest and shore sets fit perfectly (the pastel channel also covers this — don't duplicate a topic). |
| Origin stories ("why the sky is high", "how X got its name") | Built-in "why?" hook, clean twist ending. |
| Small human dramas / mini-adventures | Original cast in a race-against-time plot (a missed train, a lost letter). |
| "What if" scenarios | Impossible image in frame 0, escalation, twist. |

## Idea card format (10 per category)
**Title** (≤ 60 chars, curiosity) · **Description** (1-2 lines) · **Hook** (exact first line + first image) ·
**Story potential** ★1-5 + why · **Why it suits the look** (locations, light, the "wow" shot) ·
**Format** (Legend card 20-30 s or Story 40-55 s) · **Audience fit** (teen/adult tone).
Facts must be verified with a web search before pitching; name the source and say "versions differ" when they do.

## Script template (30-55 s, ~2.6 spoken words per second)
| Section | Time | Job |
|---|---|---|
| Hook | 0-2 s | Start in the strangest moment; strongest image on frame 0. No greetings. |
| Setup | 2-10 s | Who, where, what they want. Introduce each person in one plain sentence. |
| Escalation | 10-30 s | 2-3 beats linked with "but" / "so", each bigger; a cut every 1.5-3 s. |
| Twist / payoff | 30-45 s | The surprising fact or reversal; hold the reaction. |
| Button | last 2-4 s | A line that loops back to the hook, or a quiet final image. |
For each section write: Narration · Est. duration · Visuals (shot type + location) · Character actions · Transition.
Write for the ear: short sentences, one idea each, a clear pause between sentences.
