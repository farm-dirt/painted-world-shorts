# Examples from finished shorts (copy, don't import)
- `shotplan_<slug>.py` — a shot plan written as a small Python script that builds `project-files/project.json`
  from `timing.json`: scene helper `sc(end, location, mood, desc, camera, actors, props, fx, tr)`, captions with
  starred key words, music/SFX/CTA in one place. Re-run it after every change instead of hand-editing JSON.
- `thumb_custom_arrow.js` — the big red thumbnail arrow (`arrow` prop, rot = direction) for thumb_custom.js.
- `custom_<slug>.js` — that short's cast, props (fir, candle, bier, cross, gate, stump, axe, ribbon, gown) and
  custom sets (Carpathian village, fir mountain at dawn, candle-lit room, cemetery at dusk). Reuse pieces that
  fit a new story; every short still needs at least one new location/character/prop.
